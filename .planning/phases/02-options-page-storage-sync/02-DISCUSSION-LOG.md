## Estrutura da Options Page

| Option | Description | Selected |
|--------|-------------|----------|
| Gerenciador Multiusuário | Permite cadastrar múltiplos atendentes e ativar o atual com uma estrela de favorito. Adiciona switches globais. | ✓ |
| Perfil Único Simples | Apenas um campo de texto único para salvar o nome ativo global. | |

**User's choice:** Gerenciador Multiusuário (baseado nos prints e referências do WhatsApp Business).

---

## Método de Salvamento das Configurações

| Option | Description | Selected |
|--------|-------------|----------|
| Autosave (Salvamento Automático) | Cada mudança de checkbox, estrela ou alteração de lista é gravada instantaneamente no storage com feedback visual. | ✓ |
| Botão "Salvar" Manual | Requer que o usuário preencha e clique no botão de submit para persistir. | |

**Decision rationale:** Autosave fornece uma experiência de usuário (UX) muito mais moderna, rápida e de padrão premium (alinhada às diretrizes estéticas).
